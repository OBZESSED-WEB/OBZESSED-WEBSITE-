# OBSESSED by O&Z — Launch MVP

This is a working static e-commerce front-end based on the OBSESSED prototype.

## Included
- Responsive homepage
- Shop/product grid
- Product filters
- Working local cart with quantity controls
- Demo checkout flow
- Newsletter signup interaction
- About/story/contact sections
- Mobile responsive styling
- No build step required

## Run locally
Open `index.html` in a browser.

## Launch today
1. Go to Netlify and create/login to an account.
2. Use the option to deploy a site manually / drag-and-drop.
3. Upload the **contents of this folder** (or unzip `obsessed-by-oz-launch.zip` first).
4. Netlify will give you a public `*.netlify.app` URL.
5. Add your custom domain later if you have one.

## Important before accepting real money
The checkout in this MVP is intentionally a demo. It does NOT process payments or store orders in a database.
Before taking live orders, connect:
- PayFast / Paystack / Stripe (payment gateway)
- A real order database / ecommerce backend
- Shipping rates and delivery rules
- Real product photography
- Your final business contact details
- Privacy / POPIA-compliant policies and terms
